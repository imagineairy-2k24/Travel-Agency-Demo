# Epic 04 — Homepage

## Objective

Build the homepage as the primary brand, discovery, and conversion surface for the demo, following approved homepage structure and SEO semantic blueprint.

## Scope

Homepage sections only:

1. Hero
2. Quick planning entry (destination / dates / travellers → Start Planning)
3. Featured destinations
4. Popular tour packages
5. Car rental introduction
6. Experiences
7. Why travel with us
8. Traveller stories (placeholder)
9. Travel inspiration / guide cards
10. Final Plan Your Trip CTA

## Pages / Components

- `/` (Home)
- Reuses: Button, Section heading, Destination card, Tour card, Vehicle/category teaser, Experience card, Guide card, Header, Footer

## Implementation Tasks

| ID | Task |
| --- | --- |
| 04.01 | Implement homepage hero: full-bleed imagery, brand signal, H1 proposition, supporting copy, Plan Your Trip + Explore Destinations CTAs |
| 04.02 | Implement quick planning/search interface (destination, travel dates, travellers → Start Planning to planner with optional prefills) |
| 04.03 | Implement featured destinations section (H2 Explore Destinations) with destination cards |
| 04.04 | Implement popular tour packages section (H2 Popular Tour Packages) with tour cards |
| 04.05 | Implement car rental section with categories and Explore Vehicles CTA |
| 04.06 | Implement experiences section (travel styles: Family, Honeymoon, Adventure, etc. — illustrative) |
| 04.07 | Implement Why Travel With Us trust section (3–5 principles; no invented customer counts) |
| 04.08 | Implement traveller stories section with clearly placeholder testimonials |
| 04.09 | Implement travel guides / inspiration cards linking to the representative article |
| 04.10 | Implement final dark CTA section: Plan Your Trip |
| 04.11 | Apply homepage visual rhythm and responsive stacking |
| 04.12 | Validate one H1, logical H2s, descriptive internal links, image alt text |

## Dependencies

- Epics 01–03
- Illustrative destination/package/vehicle/guide data

## Acceptance Criteria

- Homepage communicates brand + discovery + planning CTA without explanation
- Semantic structure matches SEO homepage blueprint intent
- No invented operational claims (availability, ratings volume, partnerships)
- CTAs lead into approved demo journeys
- Mobile and desktop both usable

## Explicitly Out of Scope

- Instant booking widgets
- Live search/availability
- Stats strips with fabricated metrics
- Admin teasers
- AI chatbot
- Full experiences catalogue site section beyond homepage presentation (unless Experiences page approved)
